# Praktikumsteil der KV Elektronische Systeme 1

Implementierung und Analyse einer drahtlosen Übertragungsstrecke unter der Verwendung von Software Defined Radio (SDR) und dem CC1101 Transciever Chip.

- SDR wird als der Reciever verwendet, welcher das RF-Signal heruntermischt und weiter Signalverarbeitungsoptionen bietet (z.B. Filtern)
- Der CC1101 wird als Transmitter und Reciever verwendet, und wird von dem eLITe-Board angesteuert

Die Laboreinheit beinhaltet folgende Aufgaben

- Analyse des Zeit- und Frequenzverhalten von 2-FSK, 4-FSK und FSK
- Implementierung eines nicht-kohärenten Recievers für 2-FSK mit SDR
- Analyse der Grenzen von Baud-Rate, Sendeleistung und Reichweite der implementierten Übertragungsstrecke
